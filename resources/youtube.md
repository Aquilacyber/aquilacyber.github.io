# YouTube

Search for these channels by name. Watch to learn what to do, then do it yourself in a lab.

| Channel | Good for |
|---|---|
| Professor Messer | Networking and Security+ syllabus, clear and short |
| The Cyber Mentor | Practical ethical hacking from TCM Security |
| [IppSec](https://www.youtube.com/channel/UCa6eh7gCkpPo5XXUDfygQQA) | Walkthroughs of retired Hack The Box machines. Watch after you have tried the machine yourself |
| LiveOverflow | How vulnerabilities and exploits actually work |
| John Hammond | CTF walkthroughs and malware analysis |
| NetworkChuck | Friendly introductions to networking, Linux and security |
| David Bombal | Interviews and networking and security tutorials |
| Computerphile | Clear explanations of computing and cryptography concepts |

A longer list of channels is in the [reference section](../reference/free-training/youtube.md).
