## Rules for this folder

- Free first. A paid item is listed only when there is no free equivalent and it is clearly marked.
- One line on why it is on the list.
- If you cannot say what a beginner gets from it, it does not belong here.
- Dead link or out-of-date item? Open an issue. See [CONTRIBUTING.md](../CONTRIBUTING.md).
