# Courses

Last reviewed: 2026-10-03

Free or mostly free. Pricing and free tiers change, so check each site.

| Name | Best for | Notes |
|---|---|---|
| [Professor Messer](https://www.professormesser.com/) | Networking and Security+ syllabus | Free video courses that follow the CompTIA exam objectives |
| [Cisco Networking Academy](https://www.netacad.com/) | Networking and introductory cybersecurity | Free self-paced courses. Check the current list |
| [CS50](https://cs50.harvard.edu/x/) | Programming from scratch | Free Harvard course. The Python version is the one to take |
| [TryHackMe](https://tryhackme.com/) | Guided hands-on learning | Paths from beginner level. Free usage is limited and a paid tier adds more |
| [PortSwigger Web Security Academy](https://portswigger.net/web-security) | Web application security | Free, with hands-on labs. The best resource for web attacks |
| [Hacker101](https://www.hacker101.com/) | Web security and bug bounty | Free videos and a capture the flag from HackerOne |
| [Hack The Box Academy](https://academy.hackthebox.com/) | Structured offensive modules | Some modules are free and others are paid |
| [Microsoft Learn](https://learn.microsoft.com/en-us/training/) | Windows, Azure and Microsoft security | Free |
| [AWS Skill Builder](https://skillbuilder.aws/) | AWS and cloud security | Free tier available |
| [freeCodeCamp](https://www.freecodecamp.org/) | Web development, Python, Linux | Free |

## Order to take them in

1. Networking: Professor Messer or Cisco Networking Academy.
2. Programming: CS50 Python or Automate the Boring Stuff.
3. Guided practice: TryHackMe.
4. Web security: PortSwigger.
5. Everything else after you have picked a [track](../tracks/README.md).
