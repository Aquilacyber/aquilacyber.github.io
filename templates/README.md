## Rules for using them

- Use them on your own lab, on invented companies or on work you have permission to share. Never put a real client's name, real credentials or real personal data in a public repository.
- A template is a start. Change the headings to fit what you did.
- The NDPA checklist and the report scoring tables reflect the rules and standards as of the date above. Check the primary sources before you rely on them. They are named in each file.

## Improve them

If a template was hard to use or missed something you needed, open an issue or send a pull request. See [CONTRIBUTING.md](../CONTRIBUTING.md).
